ADDING A NEW GALLERY
1. Create a folder under assets/images/.
2. Add web-sized JPG/WebP photos.
3. Duplicate one of the gallery HTML files and update the title/image paths.
4. Add a card on index.html.

For a larger long-term photo archive, we can upgrade this to a data-driven gallery system or a photo CMS later.
